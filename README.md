Iris Flower Classification App 🌸

This project is a Machine Learning web application that predicts the species of an Iris flower using a Random Forest Classifier and a Streamlit frontend.

The model is trained using the famous Iris dataset from Scikit-learn.

Features ✨
Predicts Iris flower species
Uses Random Forest Machine Learning algorithm
Simple Streamlit web interface
Trained on Scikit-learn Iris dataset
Fast and beginner-friendly project
Technologies Used 🛠️
Python
Streamlit
Scikit-learn
Pandas
NumPy
Pickle
